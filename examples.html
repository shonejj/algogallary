Use generated art anywhere

Add one script, then mark any <img>, <video> or <canvas>. Everything renders in the visitor's browser, so there's no server, no API key and no copyright: every pixel comes from an algorithm and the output is CC0. Click any image below to reroll it.

<script type="module" src="https://shonejj.github.io/algogallary/embed.js"></script>

<img   data-algogallery="style=remix&w=1200&h=750">
<img   data-algogallery="style=creatures&seed=42&material=gummy">
<video data-algogallery="style=dreamscape&seed=7&dur=8" autoplay muted loop playsinline></video>

Other ways

A full-bleed iframe: <iframe src="https://shonejj.github.io/algogallary/render.html?style=remix&seed=5">. For plain <img src> with no JavaScript, use the pre-rendered library listed in api/library.json. Every parameter is listed in the README.
